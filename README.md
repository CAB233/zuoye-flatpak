## 使用方法

### 添加仓库
```bash
flatpak remote-add --if-not-exists zuoye-flatpak https://repo.zuoye.win/flatpak/zuoye.flatpakrepo
```

### 移除仓库
```bash
flatpak remote-delete zuoye-flatpak
```
